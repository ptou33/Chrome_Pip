# Chrome_Pip

Estensione Chrome (Manifest V3) che porta il video corrente in una finestra flottante senza bordi direttamente nella pagina. La finestra include:

- Controllo volume con slider.
- Pulsante "Prossimo video" (supporto dedicato per YouTube, fallback per altri siti).
- Pulsante di chiusura per riportare il video nella sua posizione originale.

## Utilizzo

1. Apri una pagina con un video in riproduzione.
2. Clicca l'icona dell'estensione per spostare il video nella finestra flottante.
3. Usa i controlli nella finestra per regolare il volume o passare al video successivo.
